## 🤝 Contributing

We welcome and encourage contributions from the community! If you have eBooks, articles, or any other useful resources related to Data Science, Machine Learning, or similar topics, feel free to contribute.

**How to Contribute:**
1. Fork this repository.
2. Add your resource(s) in the appropriate section or create a new section if needed.
3. Ensure your additions follow the existing style and formatting.
4. Submit a Pull Request with a clear description of your changes.

If you have suggestions or find any issues, please open an [issue](https://github.com/aniketpotabatti/Data-Science-EBooks/issues).

Thank you for making this resource better together! 🚀
